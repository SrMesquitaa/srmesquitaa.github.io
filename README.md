# Leonardo Mesquita — Portfólio

Site pessoal, publicado via GitHub Pages em [srmesquitaa.github.io](https://srmesquitaa.github.io/).

HTML, CSS, JavaScript vanilla — sem build step, hospedado direto pelo GitHub Pages.

## Rodando localmente

Basta abrir o `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
npx serve .
```
